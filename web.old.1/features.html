Features

Everything you need for private, direct, and reliable communication — no cloud required.

📡

LAN discovery & TCP

UDP broadcast finds peers automatically on the same network. TCP carries authenticated messages when you're offline — no internet needed.

🌍

Remote UDP with STUN

Public STUN lets peers discover each other's endpoints. Direct encrypted UDP tunnels punch through NATs for low-latency global communication.

🔄

DERP relay fallback

If direct UDP fails, MeshTalk Relay forwards encrypted frames through the control connection — no extra servers, just a fallback path.

🏠

Private rooms & groups

Create invite-only rooms and named group chats. Every message is encrypted separately for each recipient. Offline members get queued delivery.

📎

File transfer & preview

Send files up to 50 MiB directly between peers. Each chunk is encrypted with a fresh ephemeral key. Images appear inline; save received files anywhere.

👥

Friend requests & blocking

Friend-based social graph: accept messages only from friends. Block unwanted peers; friend requests are verified and cryptographically signed.

🖥️

OpenTUI & CLI

Full-featured terminal UI (React-powered) for chat, groups, and file management. CLI for automation, scripting, and status checks.

🔐

End‑to‑end encryption

X25519 key agreement, AES-256-GCM, Ed25519 signatures. Each message and file chunk uses a fresh ephemeral key for forward secrecy.
