Get MeshTalk

Install MeshTalk

Get started in seconds. Choose the path that fits you best.

Quick install

The quick installer downloads the latest release for your platform and places the binaries in ~/.local/bin (or %LOCALAPPDATA%\MeshTalk on Windows).

curl -fsSL https://go.qincai.xyz/getmeshtalk | bash
curl -fsSL https://go.qincai.xyz/getmeshtalk | bash -s -- --non-interactive --yes

Options: --version TAG, --install-dir DIR, --prerelease, --uninstall, --dry-run. Run with --help for the full list.

Manual install

Download the .tar.gz archive from the latest release, extract it, and run the launcher.

Download

Choose the archive for your platform: macOS (Intel/Apple Silicon), Linux (x64/ARM64), Windows (x64).

Extract

tar -xzf meshtalk-*.tar.gz (or unzip on Windows). Keep meshtalk and meshtalk-backend together.

Run

./meshtalk (macOS/Linux) or meshtalk.exe (Windows). The TUI launches with a managed backend.

Docker

Multi-arch images (amd64 and arm64) are published to GitHub Container Registry.

docker pull ghcr.io/qincai-rui/meshtalk/control:latest
docker pull ghcr.io/qincai-rui/meshtalk/client:latest
docker compose up -d
docker compose run -it client

Run from source

Requires Bun and uv.

git clone https://github.com/QinCai-rui/MeshTalk && cd MeshTalk
bun install
bun run meshtalk

Use bun run meshtalk -- --help for CLI commands, or bun run dev:tui for development.
