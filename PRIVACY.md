# MeshTalk telemetry privacy policy

Optional release telemetry consists only of anonymous version, platform, architecture, and aggregate product counters. Extended telemetry (Tier 1, the default) adds aggregate usage counters; basic telemetry sends only the version ping; telemetry can be turned off entirely. Change it anytime in Settings » Diagnostics. See [Telemetry](docs/TELEMETRY.md) for exact payloads, controls, retention, and the data never collected.
